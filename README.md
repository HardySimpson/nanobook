# 纳书 nanobook

本地优先的中文阅读器。书、进度、笔记、书单都在你自己的设备上；联网只用于取书源和可选的账号同步。

- **网页版（可直接装到主屏/桌面）**：<https://nanobook.dev>
- **下载安卓版**：<https://github.com/HardySimpson/nanobook/releases/latest>

## 这个仓库是什么

只放**发行物与更新日志**。源码不公开。每个 Release 的正文就是那一版的更新日志。

## 安装

- **安卓**：下载 `nanobook-v<版本>-arm64.apk`，允许「安装未知来源应用」后安装。覆盖升级不会丢本地书库。
- **网页版**：打开 <https://nanobook.dev>，iOS 走「添加到主屏幕」，Android 走「安装应用」。

每次发版的校验值在同一次 Release 的 `SHA256SUMS-<版本>.txt` 里，装前可以核一下。

## 问题与建议

请直接在这里提：<https://github.com/HardySimpson/nanobook/issues>

报问题时请带上：版本号（设置 → 关于）、设备与系统版本、复现步骤。
如果是某本书的排版/内容出错，请写书名与作者——不需要附上正文。
