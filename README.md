# 纳书 nanobook

本地优先的中文阅读器：书在自己设备上，进度、笔记、书单也都在本机；联网只用于取书源与可选的账号同步。

- 网页版（PWA，可直接装到桌面/主屏）：<https://nanobook.dev>
- 下载安卓版 / 桌面版：见本仓库 [Releases](https://github.com/HardySimpson/nanobook/releases/latest)

这个仓库只放**发行物与更新日志**，源码与议题在 Gitee：
<https://gitee.com/hardysimpson/nanobook>

## 安装

- **安卓**：下载 `nanobook-v<版本>-arm64.apk`，允许「安装未知来源应用」后安装。覆盖升级不会丢本地书库。
- **网页版**：用浏览器打开 <https://nanobook.dev>，iOS 走「添加到主屏幕」，Android 走「安装应用」。

每个版本的校验值在同一次 Release 的 `SHA256SUMS-<版本>.txt` 里，装前可以核一下。

## 版本说明

发行说明随 Release 一起发布，正文就是该版的更新日志。
